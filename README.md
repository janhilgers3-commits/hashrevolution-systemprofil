# HashRevolution – Systemprofil

Eigenständige, öffentliche Projektseite über Funktionen und Architektur der interaktiven Lern-Webplattform HashRevolution.

Die statische Website liegt in [`dist/index.html`](dist/index.html). Sie enthält keine Spielstände, Zugänge, internen Dokumente oder Rätsellösungen und verlinkt nicht auf die produktive Spielumgebung.

Öffentliche Seite: https://hashrevolution-systemprofil.janhilgers3.chatgpt.site

## Lokal ansehen

`dist/index.html` in einem Browser öffnen oder den Ordner `dist` mit einem lokalen Webserver bereitstellen. Für diese Projektseite sind keine Build-Abhängigkeiten erforderlich.
